## 📌 项目简介

**Lictor** 是一款面向企业业务场景自研的轻量化 Java 工作流引擎，核心聚焦 **人工审批、单据流转、多级会签** 场景。

区别于 Flowable、Activiti 等重型开源工作流，Lictor 砍掉了冗余的复杂配置与无用特性，以「**够用、简洁、高性能、可定制**」为核心设计理念，专为国内企业OA审批、业务单据评审、流程管控场景量身打造。

引擎采用**命令\-事件驱动架构**，将流程提交、驳回、回退、终止、转办等操作统一抽象为标准命令，流程全生命周期节点变更、状态流转、操作记录全部持久化留痕，完全满足企业审计、溯源合规要求。同时内置轻量调度能力，无需依赖Quartz、XXL\-Job等第三方调度框架，即可实现审批任务超时、定时流转等场景。

## ✨ 核心特性

### 🔹 强大的审批流转能力

- 支持常规审批：提交、通过、驳回、转办、协办

- **双模式回退**：驳回（退回上一节点）、任意历史节点精准回退

- 流程状态管控：运行、完成、驳回、终止、挂起、恢复全状态覆盖

- 支持会签、或签、多人审批、一票通过/一票驳回

### 🔹 内置任务调度能力

- 原生支持审批任务超时提醒、超时自动流转

- 支持定时发起、定时办结、延时审批等时序场景

- 可无缝对接第三方调度框架，灵活扩展

### 🔹 轻量化 \& 高扩展

- 核心内核零重型依赖，Jar包体积小巧

- 提供 Spring Boot Starter，开箱即用，快速接入项目

- 事件驱动设计，支持自定义流程监听、业务钩子

- 流程模型、节点规则、审批权限完全可自定义

### 🔹 全程溯源审计

- 流程实例、任务记录、操作日志、流转轨迹完整持久化

- 所有驳回、回退、终止、修改操作均留痕可追溯
